# Model credits

- `Soldier.glb`: the "Vanguard" character by T. Choonyung, via Adobe Mixamo, taken from the three.js examples (`examples/models/gltf/Soldier.glb`).
- The three.js MIT licence covers the example code, not the model.
- Mixamo's terms allow using the character inside a game, but not redistributing the file as a standalone asset,
  so this repository does not contain it: `scripts/fetch-assets.mjs` downloads it from the three.js repository
  on first run (`npm run dev`, `npm run tv` and `npm run build` do this automatically).
